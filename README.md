# Nuvio Covers

Capas personalizadas para coleções do Nuvio.

## Estrutura

- `covers/descobrir/`
- `covers/climas-e-temas/`
- `covers/filmes/`
- `covers/series/`
- `covers/anime/`
- `covers/asia-doramas/`
- `covers/desenhos/`
- `covers/animacao-familia/`
- `covers/programas-tv/`
- `covers/documentarios/`
- `covers/epocas-paises-autores/`
- `covers/category-heroes/`

Os nomes dos arquivos são versionados para evitar problemas de cache no aplicativo.

`covers/climas-e-temas/` está reservada para a nova coleção e não contém capas antigas.
